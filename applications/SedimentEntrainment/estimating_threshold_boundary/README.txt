This folder contains the data and fits for the threshold for a smooth or rough boundary layer. This is based on Figure 4).
The plots were digitized using https://plotdigitizer.com/app.

I ended up only using Figure 4 since Komar and Miller don't report the actual data points, only non-dimensional values
that can't be interchanged between Fig 4 and Fig 5. 

1. boundary_layer_threshold.m : matlab script fitting the Manohar data in Komar & Miller 1973 for smooth and turbulent 
				boundary separately
					>> display to command line shows the values for the fit used in the Wave_Flows script (Lines 95-96)
2. lam_turb_data              : data from Figure 4 in Komar and Miller 1973
3. mohar_1955_digitized_fig5  : curve points from Figure 5 in Komar and Miller 1973
4. fig4                       : Figure 4 from Komar and Miller 1973
5. fig4_annot                 : annotations for axis and points for plotdigitizer
6. fig5                       : Figure 5 from Komar and Miller 1973
7. fig5_annot                 : annotations for axis and points for plotdigitizer
